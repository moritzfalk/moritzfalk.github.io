A game in a custom engine

Independent project
Graphics & engine development

2020 — present

A custom 3D engine exploring dynamic lighting and a painterly visual style.

  • Several iterations of voxel-based dynamic global illumination, including GPU mesh voxelisation, a cache-friendly acceleration grid, and spatial and temporal denoising.
  • Stochastic alpha using interleaved gradient noise, bringing deferred decals and volumetric billboards into the deferred shading pipeline.
  • A separate tool that generates volumetric billboard data in a custom format, using an MSAA-based voxelisation method.
  • A developer UI built with microui for timing measurements, entity inspection, and debug views.

SynthForce 2099

A pseudo-3D arcade racer made by a team of four in a ten-day game jam.

2023

We coordinated across disciplines under a tight deadline. The renderer creates an arcade-style sense of depth by scaling and moving sprites, in the spirit of games like OutRun.

For placement and tuning, I implemented a small runtime tweak system. It reads the game's source and uses a hash table and a macro to reload selected variable values while the game is running.

Dynamic diffuse global illumination

A D3D11 implementation guided by NVIDIA's research paper.

2022–23

My first substantial project with a graphics API and shaders. I implemented the technique to understand probe-based lighting and its trade-offs, including probe placement and handling dynamic objects.

The implementation works, but lacks an acceleration structure and includes naïve shaders. It was a useful starting point for the later voxel-based work.

Software rasterizer

Working through the transformation and rasterisation pipeline on the CPU.

2022

Starting from tinyrenderer, I added real-time rendering, a dynamic camera, and a simple clipping method. The project helped me understand the transformation hierarchy, particularly clip space and the canonical viewing volume.

MiniRay · CPU ray tracer

BVH traversal, multithreading, and a faster path from model files to pixels.

2022

I implemented a bounding volume hierarchy and a single-producer, multiple-consumer threading scheme to work towards interactive rendering.

A custom OBJ loader caches parsed models in a custom format to avoid the cost of reparsing large files. I also removed the C runtime as an exercise in understanding and reducing dependencies.
